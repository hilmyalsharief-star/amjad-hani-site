# دليل موقع أمجد هاني

## كيف الموقع مبني
- **index.html** هو شكل الموقع (ما بتحتاج تلمسه).
- مجلد **content/** فيه كل النصوص والمشاريع والصور (ملفات JSON).
- مجلد **admin/** هو لوحة التحكم: بتفتحها على `رابط-موقعك/admin` وبتعدّل كل شي من هناك بدون برمجة.
- الصور اللي ترفعها من اللوحة بتنحفظ تلقائياً في **assets/uploads/**.

## التركيب (مرة وحدة بس، حوالي 15 دقيقة)
لوحة التحكم بتحفظ التعديلات في GitHub، والاستضافة بتنشرها تلقائياً. كله مجاني.

1. **حساب GitHub:** سجّل على github.com، وأنشئ مستودع (Repository) جديد، مثلاً `amjad-hani-site`، واجعله Public أو Private.
2. **ارفع الملفات:** من صفحة المستودع اضغط *Add file ← Upload files* واسحب **كل محتويات** هذا المجلد (مش المجلد نفسه، محتوياته)، ثم Commit.
3. **اربط الاستضافة (اختار وحدة):**
   - **Cloudflare Pages** أو **Netlify**: *Import from GitHub*، اختار المستودع، وخلّي أمر البناء (Build command) فاضي والمجلد `/`.
   - أو **GitHub Pages**: من *Settings ← Pages* اختار branch `main`.
   بعدها بيعطيك رابط الموقع.
4. **عدّل اسم المستودع:** افتح `admin/config.yml` على GitHub (أيقونة القلم)، وغيّر السطر
   `repo: YOUR-GITHUB-USERNAME/YOUR-REPO-NAME` إلى اسمك واسم المستودع، مثال `repo: ahmad123/amjad-hani-site`.
5. **أنشئ مفتاح دخول (Token):** GitHub ← Settings ← Developer settings ← Personal access tokens ← *Fine-grained tokens* ← Generate new token. اختار المستودع تبعك فقط، وفي Permissions خلّي **Contents = Read and write**. انسخ المفتاح.
6. افتح `رابط-موقعك/admin` واضغط **Sign in with token**، والصق المفتاح. (بيتذكرك على نفس المتصفح.)

## الاستخدام اليومي
من `/admin` بتلاقي القائمة:
- **المشاريع**: إضافة مشروع (الاسم بالعربي والإنجليزي، النوع، الصورة)، حذف، إخفاء مؤقت، وترتيب بالسحب.
- **الفريق**: إضافة أشخاص مع صورهم. أول ما تضيف شخص، بتختفي عبارة "ستُضاف لاحقاً".
- **الصور**: صور قسم التصوير.
- **مجالات الخبرة**: إضافة أو تعديل المجالات.
- **نصوص الموقع وبقية الأقسام**: كل العناوين والنصوص (عربي + English) وصور الواجهة وإيميل وهاتف ورابط السوشال.

بعد التعديل اضغط **Save / Publish**، وخلال دقيقة أو دقيقتين الموقع بيتحدّث لحاله.

## ملاحظات
- أي نص بتتركه **فاضي** بيختفي من الموقع (مفيد لملاحظات "تجريبية" وغيرها).
- إذا ما كتبت النص العربي، بيظهر النص الإنجليزي مكانه.
- الصور الحالية تجريبية (Unsplash). غيّرها من اللوحة بصورك.
- ما تحذف أو تغيّر أسماء الملفات داخل `content/` يدوياً.
